# Drupal IXP Program Registration Site

### Tools & Skills: Front End Development, Designer, UX, Drupal 11, Twig, HTML, SASS, GitHub, Figma, Photoshop
[View Live Site](https://drupal-ixp.site/)

## Problem: 
The Drupal IXP Program needed a registration site very quickly to register participants in the Drupal-sponsored internship program and a tracking platform for program data. The registration flow and tracking data for an Agency was different from a Volunteer, vs an IXP Developer Intern.

## Solution: 
We themed a customized Drupal 11 site quickly on a custom Radix sub-theme. Radix uses Bootstrap 5, SASS and has component-driven theming and has evolved to leverage Single Directory Components in Drupal core. We created custom views and SDC’s for each persona’s registration and usage experience.

## Implementation Role: 
I designed the website, protoyped the user flows, and then was responsible for Theming and Front-End implementation of the design elements, as well as acting in a Site Builder role by creating the custom views and content as needed.
